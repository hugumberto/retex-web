# RetexWeb

## Run Commands

### Start the Next.js app

```sh
npx nx serve portal
```

### Build the app

```sh
npx nx build portal
```

### Run tests

```sh
npx nx test portal
```

### Lint

```sh
npx nx lint portal
```

### Show dependency graph

```sh
npx nx graph
```
